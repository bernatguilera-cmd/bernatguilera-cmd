## 🚀 Shared. – my startup idea
**Shared.** is a fintech app for group money. A group of friends, flatmates or a club puts money
into a common fund *before* spending it, pays with a virtual card linked to the fund, and gets the
leftover back automatically when the fund closes. Nobody has to chase debts or split bills
afterwards.

- **The idea and the product are mine**: the concept, the business model, the user flows and the
  financial rules (contributions, top-ups, Premium per fund, settlement).
- I built the prototypes myself with Replit's AI agent, from my own specifications.
- A developer is now building the production backend API from my product requirements.
